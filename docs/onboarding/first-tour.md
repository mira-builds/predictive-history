The first tour is not a repository review. It is the default guided entry into the Predictive History **namespace catalog hub** via the 10-route literary spine seed.

## Reader Promise

In ten stops, the reader sees civilizational memory and literary grammar on the spine, then application routes under modern pressure.

## Opening Move

Begin at `civ-07`.

Explain it as the Homeric memory system: heroic action becomes a grammar of honor, violence, inherited imagination, and civilizational memory. Keep the guardrail visible: Homer-to-Tolstoy is the literary spine route, not a claim that literature alone drives history.

Before making chapter-specific claims, return to:

- `data/cards/civ-07.md`
- `lectures/civilization/civ-07/civ-07-transcript.md`
- `lectures/civilization/civ-07/civ-07-commentary.md`
- `lectures/civilization/civ-07/civ-07-commentary.md` for the commentary canvas

## Tour Phases

### Literary Spine

Stops: `civ-07`, `civ-17`, `civ-29`, `civ-51`

This phase shows how literary memory becomes civilizational grammar without claiming literature alone drives history.

### Close-Reading Reinforcement

Stops: `gb-02`, `gb-09`

This phase returns to Homer and Dante as reading engines so the spine is not only a survey path.

### Application Exposure

Stops: `geo-14`, `gt-16`, `sh-16`, `sh-28`

This phase shows the laws under geopolitical, incentive, Tolstoy-coda, and infrastructure pressure while keeping application routes bounded.

## Ten Stops

1. `civ-07` - Homer as civilizational memory system.
2. `civ-17` - Virgil and Rome as the hinge from heroic memory to imperial destiny.
3. `civ-29` - Dante as sacred architecture.
4. `civ-51` - Shakespeare as language machine.
5. `gb-02` - Homer close reading as human invention.
6. `gb-09` - Dante close reading as desire, guilt, punishment, and ascent.
7. `geo-14` - geographic pressure.
8. `gt-16` - incentive pressure.
9. `sh-16` - Tolstoy endpoint via Anna Karenina coda, not a dedicated Tolstoy lecture.
10. `sh-28` - infrastructure as symbolic pressure.

## Guardrails

- `sh-16` is a Tolstoy endpoint via an Anna Karenina coda, not a dedicated Tolstoy lecture.
- Application routes are public orientation only, not live operational analysis.
- Commentaries are open project canvases, not final scholarly review.
- Chapter folders are the study surface; the namespace catalog is the hub.
