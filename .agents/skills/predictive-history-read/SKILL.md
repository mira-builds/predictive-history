# Predictive History Read

Resolve the requested chapter ID or route using the public catalog and existing CLI. Paths below are relative to the repository root, three directories above this skill.

- Read `START-HERE.md` and use `docs/predictive-history-index.json` to resolve the chapter. `predictive-history show civ-07 --format json`, `predictive-history link civ-07 --json`, and `predictive-history path homer-to-tolstoy` expose existing navigation.
- Open the chapter doorway, then its transcript or essay/interview body before interpreting. Use `docs/methodology/source-lattice.md` for traversal; commentary and cards are orientation and interpretation, not replacements for source wording.
- Select a bounded passage relevant to the reader's question. Identify the chapter, section or paragraph opening, source URL when available, and actual passage limits. Preserve speaker attribution and distinguish a transcript's report of a literary work from that work itself.
- Explain what the passage supports, how commentary interprets it, and where uncertainty remains. Label modern analogy as analogy and test an important difference before widening a historical comparison.
- Invite the reader's interpretation or correction when useful. A reading can finish with a supported explanation and an open question; exercises, assessment, and saving are optional.

If a body or chapter is unavailable, state exactly what is missing. Do not substitute recalled prose, invent quotations, or imply that an excerpt represents a whole work. Original-language or edition verification requires the relevant source, not a translated lecture account.

Homer-to-Tolstoy remains the literary spine. `sh-16` carries a Tolstoy coda rather than a dedicated Tolstoy lecture. Commentaries retain their visible review status. Use only public project files; this skill requires no private journal, runtime, provider, or automatic retention.
