# Predictive History Learn

Use paths relative to the repository root, three directories above this skill. Start from the learner's requested chapter, question, audience, and useful finish line; ask only for missing information that changes the activity.

Resolve the chapter through `docs/predictive-history-index.json` or `predictive-history show SOURCE_ID --format json`. Read its source body and visible review limits. Follow `docs/methodology/source-lattice.md`; use the neighboring `predictive-history-read` skill when a bounded textual encounter would help.

Shape one proportionate activity around supported material: an explanation, passage comparison, seminar question, counter-reading, or optional application. Existing `predictive-history prompt SOURCE_ID --mode seminar` and `--mode counter-reading` supply provider-neutral templates; they do not generate evidence or call a model service.

When practice is requested, invite an explanation or prediction, point to evidence, offer a conceptual hint, and demonstrate only as much as is useful. Give feedback on the actual response, identifying support, gaps, and assistance. The learner may disagree, change direction, or request a direct explanation without completing an exercise.

Keep the source's claim, an interpretive proposal, and the learner's response distinct. A polished output or completed activity does not establish mastery or independent capability. A useful explanation may complete the task without assessment. Contemporary applications are bounded orientation; verify external factual claims separately when needed.

If the required source is missing, explain the limitation and continue only with material actually available. Do not invent reading history, learner profiles, scholarship, quotations, or source coverage. No journaling, learner records, publication, or automatic saving follows from using this skill.
